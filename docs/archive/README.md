# Archive Directory (Closed Tasks & Documents)

This folder contains closed and archived project documents, including completed Epics, finished PRDs, and resolved bugfix plans.

## How to Archive a Document

When a task or epic is finished:
```bash
mv docs/epics/EPIC-XXX.md docs/archive/EPIC-XXX.md
```
Then log the record in the table above.
